# 感應視覺設計工作室 SPA 網站
依據 261110 修改後網站架設企劃書 v4 與提供的 12 張圖片製作。

## 開啟方式
1. 將整個 ZIP 解壓縮，保留資料夾結構。
2. 使用近期版本 Chrome、Edge、Firefox 或 Safari 開啟 index.html。
3. 不需要 npm、Node.js、資料庫或編譯。網站圖片、樣式、動畫套件均已包含。
4. 若要上線，將 index.html、css、js、images、vendor 一起上傳至靜態網站空間。本交付未部署或公開發布。

## 檔案
- index.html：15 個章節、導覽、表單、燈箱與中英文字。
- css/style.css：黑／金／灰／白設計、響應式、LED、跑馬燈、動畫。
- js/main.js：作品資料、分類、燈箱、輪播、語言、黑蛋互動、計數、Canvas 粒子及表單。
- images/：12 張網頁用高畫質 JPEG，保留原始像素尺寸。PNG 已轉成 JPEG，檔名去除附件重複編號。
- vendor/：本機 WOW.js 1.1.2 與 Animate.css 4.1.1，無須連線 CDN。
- THIRD_PARTY_LICENSES.txt：第三方套件授權。

## 互動
- 15 宮格全螢幕選單、桌機右側章節導覽、ScrollSpy、平滑錨點。
- 首頁 3 圖切換、流動粒子與滑鼠感應、可暫停動畫。
- 精選作品 4 類篩選、6 件作品燈箱、上下件切換、ESC 或外部背景關閉。
- 旗艦輪播支援左右鍵、觸控滑動、上一張／下一張、暫停及進度條。
- 黑蛋每點一次增加 25% 能量，也可拖曳或鍵盤調整滑桿；100% 顯示黃金章魚與隨機靈感，支援重設。
- FAQ 摺疊、數據計數、服務快速帶入表單、預算滑桿。
- 主要文案繁中／英文切換。圖片替代文字及部分輔助標籤保留繁中。
- 響應式與 prefers-reduced-motion 支援。

## 實作取捨
以可直接離線開啟的靜態單頁實現 SPA 瀏覽體驗。首頁流體採輕量 Canvas 粒子感應近似，非 WebGL 流體求解器；破殼採 SVG 牢籠解構、影像替換與 CSS 動畫。避免重型 3D 運算，兼顧手機效能。
